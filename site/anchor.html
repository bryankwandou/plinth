Solana devnet

A receipt that proves which deck passed the linter

Drop a deck file. The page hashes it and scores it in your browser, then writes plinth:v1 sha256=… score=… as a memo on Solana devnet. A judge can later drop the same file next to the signature and see if it matches, byte for byte.

Write a receipt

Needs a Solana wallet such as Phantom or Solflare set to devnet. The file never leaves your machine; only the hash goes on chain.
